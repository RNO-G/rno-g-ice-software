# RNO-G data acquisition (DAQ) software

Programs running on RNO-G SBCs to take data.

A manual for the operations of the RNO-G stations can be found [in the documentation repository on GitHub.](https://github.com/RNO-G/rno-g-docs/tree/master)

Dependencies:
- The RNO-G i/o and hardware libraries (librno-g.so and libradiant.so) - [librno-g repository](https://github.com/RNO-G/librno-g)
- libconfig
